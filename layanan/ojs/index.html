Pertanyaan Umum (FAQ) Frequently Asked Questions

Apakah sudah termasuk ISSN? Does it include ISSN?

Ya, semua paket sudah termasuk E-ISSN dan P-ISSN (jika dicetak). Tim kami akan membantu proses permohonan ISSN ke LIPI secara lengkap. Yes, all packages include E-ISSN and P-ISSN (if printed). Our team will help with the complete ISSN application process to LIPI.

Apakah sudah termasuk DOAJ? Does it include DOAJ?

DOAJ (Directory of Open Access Journals) termasuk dalam paket Exclusive 1, 2, dan 3. Untuk paket Hemat dan Medium, DOAJ bisa ditambahkan sebagai opsi tambahan. DOAJ (Directory of Open Access Journals) is included in Exclusive 1, 2, and 3 packages. For Budget and Medium packages, DOAJ can be added as an optional add-on.

Berapa lama proses pengerjaan? How long is the process?

Proses setup OJS biasanya membutuhkan 2-3 minggu dari pembayaran hingga launch. Ini termasuk instalasi, kustomisasi, integrasi ISSN, dan training pengguna. Permohonan ISSN ke LIPI membutuhkan waktu 2-4 minggu terpisah. The OJS setup process typically takes 2-3 weeks from payment to launch. This includes installation, customization, ISSN integration, and user training. ISSN application to LIPI takes 2-4 weeks separately.

Apakah mendapat pelatihan? Is training provided?

Iya, paket Medium dan Exclusive sudah termasuk pelatihan via Zoom (2-3 sesi). Paket Hemat bisa mendapat pelatihan dengan biaya tambahan. Semua paket juga mendapat video tutorial lengkap. Yes, Medium and Exclusive packages include Zoom training (2-3 sessions). Budget package can get training with additional cost. All packages include complete video tutorials.

Apakah mendapat akses hosting? Do we get hosting access?

Ya, paket Exclusive 1, 2, dan 3 sudah termasuk akses CPanel penuh. Paket Medium juga bisa mendapat akses CPanel dengan permintaan khusus. Paket Hemat bisa menambahkan akses CPanel dengan biaya tambahan. Yes, Exclusive 1, 2, and 3 packages include full CPanel access. Medium package can also get CPanel access upon request. Budget package can add CPanel access for additional cost.
